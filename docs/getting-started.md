# Installation, Usage & Configuration Guide

## Installation

Install the package:

```bash
bun add -D @opinionated-ts/config
```

## Usage

Once installed, configure each tool to use the opinionated defaults provided by this package.

- [TypeScript Configuration](./tsconfig.md)
